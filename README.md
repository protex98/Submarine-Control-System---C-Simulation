# 🚢 Submarine Control System - C# Simulation

A complete submarine control system simulator built in **C#** with a text-based interface. This project mimics a real submarine's onboard computer, managing navigation, life support, and emergency protocols.

## ✨ Features
- **Propulsion Control** (speed, engine status)
- **Depth Management** (dive, surface, pressure monitoring)
- **Sonar System** (target detection, scanning)
- **Vital Support** (O₂ levels, battery consumption)
- **Emergency Mode** (rapid surfacing, system shutdown)
- **Real-time Monitoring** (sensors, alerts, diagnostics)

## 🛠 Technologies
- **C#** (.NET Core)
- **Object-Oriented Programming** (OOP)
- **Console-Based UI** (menu-driven interaction)
- **Simulation Logic** (physics, resource management)
